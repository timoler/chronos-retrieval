## 作图开始前

先看任务书，再使用对应 CSV。图 1 和图 2 是结构图，图 3–5 是数据与知识记录图；图 S1–S2 为补充图。不要从旧截图抄数，不混用原始聚合与均值对齐协议，不补画尚未完成实验。

主矩阵统计采用三种子样本标准差 ddof=1；旧内部表保留 ddof=0。四底座均使用同一数据集和种子的 PAER 记忆；Chronos-2 底座预测共享，插件种子不同。

## 可复算性

本包包含同门绘图所需的小型数据，不包含大体积模型权重、预测数组或第三方论文 PDF。`MANIFEST.json` 给出包内文件 SHA256。`PACKAGE_CHECKS.json` 记录结构检查，`figure_data/fig04_source_hashes.json` 记录误差分解的本地预测来源哈希。完整缓存复算需另有仓库所述的本地预测包。

正文与表格更新须同时更新数字来源。数值改变后重新生成图，不在 PDF 中手改。新图建议提交至 `paper/figures/`，文件名按任务书固定。
