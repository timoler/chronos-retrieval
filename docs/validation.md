# 发布实现的核验

仓库内的代码按冻结实验的数值操作整理为 Python 包。研究数据和生成的专家对象使用明确的输入文件，训练、检索和评分共用同一组参数与时间边界。

| 检查 | 覆盖 | 结果 |
|---|---|---|
| 知识条件编译、贡献判定 | 7 项任务的 21 个活动池、126 条状态与奖励 | 与冻结记录一致 |
| 新旧修订接受规则 | 70 次有序的单条替换比较 | 全部与实际决定一致，16 次接受 |
| 固定检索器前向 | Weather、Exchange 的初始与最终知识池，各 32 个旧 VAL 窗口 | Top-5、原始均值预测与均值对齐预测逐元素一致 |
| 从真实输入重新训练、选择融合权重、评价 TEST | ETTh2、Chronos-2、种子 42、原 30 个 epoch | λ、融合 MSE 和 MAE 与冻结记录一致 |
| 七任务与消融结果表 | 252 行主结果、480 行五任务组件对照 | 可用标准库核对汇总 |
| 新月份的预测误差与时间块区间 | 4 个底座、4 种配置、3 个种子 | 从官方归档和保存的预测核对 48 行指标和 24 项配对比较 |

完整七任务论文表来自已完成的冻结运行。公开包支持从提供的初始池和保存的修订提议重跑。重新请求语言模型可能产生不同的提议。历史生成调用的模型快照与采样设置只有部分记录。
